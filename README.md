# Wisdom Portfolio

A responsive front-end developer portfolio built with plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open the `wisdom-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Files
- `index.html` — page structure and content
- `style.css` — colours, layout, responsive breakpoints, animations, transitions
- `script.js` — mobile hamburger menu, scroll reveal, animated skill bars, footer year, demo email form
- `images/wisdom-tech-avatar.png` — cartoon developer avatar

## Personalise before publishing
- Replace the sample project cards/links with your actual project demos or GitHub repositories.
- In `script.js`, replace `your-email@example.com` with your real email address.
- In `index.html`, replace the Facebook, TikTok, and GitHub homepage links with your own profile URLs.
- Edit the hobbies so they match your real interests.
- The skill percentages are self-assessed learning progress, not formal proficiency ratings.

Fonts load from Google Fonts when online; the page still works if you are offline, using fallback fonts.
